# 8 Ball Helper

By **decryptable**. Public builds for 8 Ball Duels. Development source is private.

```lua
loadstring(game:HttpGet("https://github.com/decryptable/8-ball-helper-releases/releases/latest/download/8-ball-helper.luau"))()
```

Minimize to the floating button. On desktop, **RightShift** toggles the window. Close or Unload removes the helper. Autoplay starts off on every load.

Only experience `10526463655`, place `116921506811323` is accepted. Predictions are local and do not guarantee wins. Published bundles can be inspected by anyone who downloads them.

See [releases](https://github.com/decryptable/8-ball-helper-releases/releases) for pinned loaders, checksums, and the bundled WindUI license.
